# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MasterG, please do not disclose it publicly.
Instead, send an email describing the issue with reproduction steps to the project maintainers.

We will review your submission promptly and coordinate a patch and release before public disclosure.
